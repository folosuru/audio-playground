# whisper

音声をささやき声にしたい

## 手法
今のところ: 
- ボコーダで分離してホワイトノイズで駆動させる
- スペクトル包絡に対してPhantom Silhouette方式に基づいた加工を行う
  - 低周波数帯のシフト
  - 高周波数帯の補償
  - 低周波数のカット
